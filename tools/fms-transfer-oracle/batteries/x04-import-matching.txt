# Import Records probes (battery x04): the import review's P2 and P4
# (script-steps.md, "Implementation notes (import/export)"). P2: updates
# into a table other than the window's (Contacts' window, Addresses target):
# which records "update existing" (Replace) and "update matching" (Update)
# work on. P4: whether update matching compares match values as text or as
# FileMaker's index does (case, numbers by value, dates). Hand-written; the
# sources are in sources/x04.

== Clear
Go to Layout [ "Contact List" ]
Show All Records
Loop
Exit Loop If [ Get ( FoundCount ) = 0 ]
Delete Record/Request [ With dialog: Off ]
End Loop

== Dump
Go to Layout [ "Contact List" ]
Show All Records
Step 21
Set Variable [ $p0 ; Get ( DocumentsPath ) & "omprobe_r_" & Get ( ScriptParameter ) & ".xml" ]
Export Records [ "file:$p0" ; Type: XMLE ; Charset: 4 ; Fields: Contacts::K | Contacts::First Name | Contacts::Last Name | Contacts::N | Contacts::D | Contacts::T | Contacts::TS | Contacts::R | Contacts::NR | Contacts::AE | Contacts::AEO | Contacts::VNE | Contacts::VNO | Contacts::VU | Contacts::CreatedBy | Contacts::PrimaryKey | Contacts::Title | Addresses::City ; With dialog: Off ]

== Make
# parameter: K values separated by returns; each record gets First Name old<K>
Set Variable [ $i ; 1 ]
Loop
Exit Loop If [ $i > ValueCount ( Get ( ScriptParameter ) ) ]
New Record/Request
Set Field [ Contacts::K ; GetValue ( Get ( ScriptParameter ) ; $i ) ]
Set Field [ Contacts::First Name ; "old" & GetValue ( Get ( ScriptParameter ) ; $i ) ]
Set Field [ Contacts::VNE ; "pre" ]
Set Field [ Contacts::VNO ; "pre" ]
Set Field [ Contacts::PrimaryKey ; "C" & GetValue ( Get ( ScriptParameter ) ; $i ) ]
Set Variable [ $i ; $i + 1 ]
End Loop
Commit Records/Requests [ With dialog: Off ]

== MakeN
# parameter: N values separated by returns; record i gets K n<i>, First Name old<i>
Set Variable [ $i ; 1 ]
Loop
Exit Loop If [ $i > ValueCount ( Get ( ScriptParameter ) ) ]
New Record/Request
Set Field [ Contacts::K ; "n" & $i ]
Set Field [ Contacts::First Name ; "old" & $i ]
Set Field [ Contacts::N ; GetValue ( Get ( ScriptParameter ) ; $i ) ]
Set Field [ Contacts::D ; Date ( $i ; 2 ; 2026 ) ]
Set Field [ Contacts::VNE ; "pre" ]
Set Field [ Contacts::VNO ; "pre" ]
Set Variable [ $i ; $i + 1 ]
End Loop
Commit Records/Requests [ With dialog: Off ]
