# Auto-entered calculations and a validation calculation that read an
# unstored calculation or a summary field of their own table, on FileMaker
# Server's script engine. Run on contacts-en with fields 14-19 that
# s44_unstored_schema.py adds (SCHEMA=<its output>): U = First Name & "!"
# (unstored), A1 = U & "?" (replacing), A2 the same with "Do not replace
# existing value", V1 validated Always by U ≠ "x!" (also when not
# modified), S = Count of First Name (summary), A3 = S & "#" (replacing).
# Each step is Set Field and Commit Records in one new Contacts record.

== probe
Set Error Capture [ On ]
Go to Layout [ "Contact Details" ]
New Record/Request
Set Variable [ $log ; "0 made " & Contacts::U & "/" & Contacts::A1 & "/" & Contacts::A2 & "/" & Contacts::A3 ]
Commit Records/Requests [ With dialog: Off ]
Set Variable [ $log ; $log & ¶ & "1 committed " & Get ( LastError ) & " " & Contacts::U & "/" & Contacts::A1 & "/" & Contacts::A2 & "/" & Contacts::A3 ]
Set Field [ Contacts::First Name ; "a" ]
Set Variable [ $log ; $log & ¶ & "2 set a " & Contacts::U & "/" & Contacts::A1 & "/" & Contacts::A2 & "/" & Contacts::A3 ]
Commit Records/Requests [ With dialog: Off ]
Set Variable [ $log ; $log & ¶ & "3 committed a " & Get ( LastError ) & " " & Contacts::U & "/" & Contacts::A1 & "/" & Contacts::A2 & "/" & Contacts::A3 ]
Set Field [ Contacts::First Name ; "b" ]
Commit Records/Requests [ With dialog: Off ]
Set Variable [ $log ; $log & ¶ & "4 committed b " & Get ( LastError ) & " " & Contacts::U & "/" & Contacts::A1 & "/" & Contacts::A2 & "/" & Contacts::A3 ]
Set Field [ Contacts::Last Name ; "z" ]
Commit Records/Requests [ With dialog: Off ]
Set Variable [ $log ; $log & ¶ & "5 other field " & Get ( LastError ) & " " & Contacts::U & "/" & Contacts::A1 & "/" & Contacts::A2 & "/" & Contacts::A3 ]
Set Field [ Contacts::First Name ; "x" ]
Commit Records/Requests [ With dialog: Off ]
Set Variable [ $log ; $log & ¶ & "6 first x " & Get ( LastError ) & " " & Contacts::First Name & "/" & Contacts::U & "/" & Contacts::A1 ]
Revert Record/Request [ With dialog: Off ]
Set Variable [ $log ; $log & ¶ & "7 reverted " & Contacts::First Name & "/" & Contacts::U & "/" & Contacts::A1 & "/" & Get ( FoundCount ) ]
Exit Script [ $log ]

== modified
Set Error Capture [ On ]
Go to Layout [ "Contact Details" ]
New Record/Request
Set Field [ Contacts::First Name ; "x" ]
Commit Records/Requests [ With dialog: Off ]
Set Variable [ $e ; Get ( LastError ) ]
Set Field [ Contacts::First Name ; "y" ]
Commit Records/Requests [ With dialog: Off ]
Exit Script [ "x " & $e & " then y " & Get ( LastError ) & " " & Contacts::U & "/" & Contacts::A1 & "/" & Contacts::A3 ]

--- run
probe
