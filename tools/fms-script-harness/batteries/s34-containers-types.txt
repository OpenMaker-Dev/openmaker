# Which stream type Set Field gives decoded data in a container field (the
# file name's extension or the bytes), and what the picture functions read
# from a stored picture with no SIZE stream. Base file: contacts-en
# (Contacts::Photo). Each script stores one value in a new record; the
# library members are read from the run copy afterwards.
== store
New Record/Request
Set Field [ Contacts::Photo ; Base64Decode ( Get ( ScriptParameter ) ; GetValue ( $$names ; 1 ) ) ]
Set Variable [ $$open ; GetAsText ( Contacts::Photo ) & "|" & Length ( Contacts::Photo ) & "|" & GetWidth ( Contacts::Photo ) & "x" & GetHeight ( Contacts::Photo ) & "|" & GetContainerAttribute ( Contacts::Photo ; "internalSize" ) ]
Commit Records/Requests [ With dialog: Off ]
Set Variable [ $$committed ; GetAsText ( Contacts::Photo ) & "|" & Length ( Contacts::Photo ) & "|" & GetWidth ( Contacts::Photo ) & "x" & GetHeight ( Contacts::Photo ) & "|" & GetContainerAttribute ( Contacts::Photo ; "internalSize" ) & "|" & GetAsText ( GetThumbnail ( Contacts::Photo ; 2 ; 2 ) ) & "|" & GetContainerAttribute ( Contacts::Photo ; "width" ) & "|" & GetContainerAttribute ( Contacts::Photo ; "fileType" ) ]
Set Variable [ $$id ; Get ( RecordID ) ]
Exit Script [ Get ( LastError ) ]
