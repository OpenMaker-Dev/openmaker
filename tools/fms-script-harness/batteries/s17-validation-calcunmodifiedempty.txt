# Validation of a repeating field (three repetitions), script-runtime.md
# 13.19. Website: by calculation not IsEmpty ( Self ), strict, Always, validate only if modified off (0x2). Probe file contacts-calcunmodifiedempty.fmp12: crates/om-server
# example validation_probe (rule calcunmodifiedempty) over contacts-en; the @trigger line
# (never fired) makes runbat.sh run FMUpgradeTool's file generated from it.
# Each probe exits with Set Field's errors, then Commit Records' ("set/commit");
# a refused record is deleted (new) or reverted (Step 51), as a failed commit
# otherwise leaves the file unable to close (803 on the next run).
@trigger	Contact List	OnGestureTap	count
== none
Set Error Capture [ On ]
New Record/Request
Set Field [ Contacts::Company ; "x" ]
Set Variable [ $set ; $set & Get ( LastError ) ]
Commit Records/Requests [ With dialog: Off ]
Set Variable [ $e ; Get ( LastError ) ]
If [ $e ≠ 0 ]
Delete Record/Request [ With dialog: Off ]
End If
Exit Script [ $set & "/" & $e ]
== only rep1
Set Error Capture [ On ]
New Record/Request
Set Field [ Contacts::Website[1] ; "a" ]
Set Variable [ $set ; $set & Get ( LastError ) ]
Commit Records/Requests [ With dialog: Off ]
Set Variable [ $e ; Get ( LastError ) ]
If [ $e ≠ 0 ]
Delete Record/Request [ With dialog: Off ]
End If
Exit Script [ $set & "/" & $e ]
== all three
Set Error Capture [ On ]
New Record/Request
Set Field [ Contacts::Website[1] ; "a" ]
Set Variable [ $set ; $set & Get ( LastError ) ]
Set Field [ Contacts::Website[2] ; "b" ]
Set Variable [ $set ; $set & Get ( LastError ) ]
Set Field [ Contacts::Website[3] ; "c" ]
Set Variable [ $set ; $set & Get ( LastError ) ]
Commit Records/Requests [ With dialog: Off ]
Set Variable [ $e ; Get ( LastError ) ]
If [ $e ≠ 0 ]
Delete Record/Request [ With dialog: Off ]
End If
Exit Script [ $set & "/" & $e ]
== count
Exit Script [ ExecuteSQL ( "SELECT COUNT(*) FROM Contacts" ; "" ; "" ) ]
