# Validation of a repeating field (three repetitions), script-runtime.md
# 13.19. Job Title: unique, value index, strict, Always. Probe file contacts-unique.fmp12: crates/om-server
# example validation_probe (rule unique) over contacts-en; the @trigger line
# (never fired) makes runbat.sh run FMUpgradeTool's file generated from it.
# Each probe exits with Set Field's errors, then Commit Records' ("set/commit");
# a refused record is deleted (new) or reverted (Step 51), as a failed commit
# otherwise leaves the file unable to close (803 on the next run).
@trigger	Contact List	OnGestureTap	count
== u first
Set Error Capture [ On ]
New Record/Request
Set Field [ Contacts::Job Title[1] ; "x" ]
Set Variable [ $set ; $set & Get ( LastError ) ]
Commit Records/Requests [ With dialog: Off ]
Set Variable [ $e ; Get ( LastError ) ]
If [ $e ≠ 0 ]
Delete Record/Request [ With dialog: Off ]
End If
Exit Script [ $set & "/" & $e ]
== u rep2 equals rep1 of other
Set Error Capture [ On ]
New Record/Request
Set Field [ Contacts::Job Title[2] ; "x" ]
Set Variable [ $set ; $set & Get ( LastError ) ]
Commit Records/Requests [ With dialog: Off ]
Set Variable [ $e ; Get ( LastError ) ]
If [ $e ≠ 0 ]
Delete Record/Request [ With dialog: Off ]
End If
Exit Script [ $set & "/" & $e ]
== u rep2 new
Set Error Capture [ On ]
New Record/Request
Set Field [ Contacts::Job Title[2] ; "y" ]
Set Variable [ $set ; $set & Get ( LastError ) ]
Commit Records/Requests [ With dialog: Off ]
Set Variable [ $e ; Get ( LastError ) ]
If [ $e ≠ 0 ]
Delete Record/Request [ With dialog: Off ]
End If
Exit Script [ $set & "/" & $e ]
== u rep1 equals rep2 of other
Set Error Capture [ On ]
New Record/Request
Set Field [ Contacts::Job Title[1] ; "y" ]
Set Variable [ $set ; $set & Get ( LastError ) ]
Commit Records/Requests [ With dialog: Off ]
Set Variable [ $e ; Get ( LastError ) ]
If [ $e ≠ 0 ]
Delete Record/Request [ With dialog: Off ]
End If
Exit Script [ $set & "/" & $e ]
== u rep3 equals rep2 of other
Set Error Capture [ On ]
New Record/Request
Set Field [ Contacts::Job Title[3] ; "y" ]
Set Variable [ $set ; $set & Get ( LastError ) ]
Commit Records/Requests [ With dialog: Off ]
Set Variable [ $e ; Get ( LastError ) ]
If [ $e ≠ 0 ]
Delete Record/Request [ With dialog: Off ]
End If
Exit Script [ $set & "/" & $e ]
== u same record twice
Set Error Capture [ On ]
New Record/Request
Set Field [ Contacts::Job Title[1] ; "z" ]
Set Variable [ $set ; $set & Get ( LastError ) ]
Set Field [ Contacts::Job Title[2] ; "z" ]
Set Variable [ $set ; $set & Get ( LastError ) ]
Commit Records/Requests [ With dialog: Off ]
Set Variable [ $e ; Get ( LastError ) ]
If [ $e ≠ 0 ]
Delete Record/Request [ With dialog: Off ]
End If
Exit Script [ $set & "/" & $e ]
== count
Exit Script [ ExecuteSQL ( "SELECT COUNT(*) FROM Contacts" ; "" ; "" ) ]
