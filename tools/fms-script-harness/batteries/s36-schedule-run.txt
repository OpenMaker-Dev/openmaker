# What a schedule's run looks like to its script (script-runtime.md
# "Implementation notes (schedules)"): every run line is a fresh session
# started as fmsased starts a FileMaker script schedule
# (SMSession::RunScriptAndClose with the schedule's file, account, script
# name and parameter). Script names in other cases or with spaces, a missing
# or empty name, parameters (empty, a calculation's text, returns, non-ASCII),
# the Get answers of the session, results and errors, `$$` variables across
# runs, real accounts (a wrong password, an unknown account, the name in
# another case, the template's disabled [Guest]) and a file that cannot be
# opened (`@path`). Base file: contacts-en.
== sched context
Exit Script [ Get ( ScriptName ) & "|" & Get ( ScriptParameter ) & "|" & Length ( Get ( ScriptParameter ) ) & "|" & Get ( AccountName ) & "|" & Get ( UserName ) & "|" & Get ( WindowName ) & "|" & Get ( ApplicationVersion ) & "|" & Get ( ScriptResult ) & "|" & Get ( LastError ) & "|" & Get ( LayoutName ) & "|" & Get ( FoundCount ) & "|" & Get ( ErrorCaptureState ) & "|" & Get ( AllowAbortState ) & "|" & Get ( CurrentPrivilegeSetName ) & "|" & Get ( WindowMode ) ]
== sched param
Exit Script [ GetAsNumber ( Get ( ScriptParameter ) ) & "|" & IsEmpty ( Get ( ScriptParameter ) ) & "|" & Evaluate ( Get ( ScriptParameter ) ) & "|" & Code ( Get ( ScriptParameter ) ) ]
== sched set global
Set Variable [ $$g ; Get ( ScriptParameter ) ]
Exit Script [ "set " & $$g ]
== sched read global
Exit Script [ "g=" & $$g ]
== sched error
Go to Record/Request/Page [ Next ]
Set Variable [ $e ; Get ( LastError ) ]
Exit Script [ "after " & $e ]
== sched error last
Exit Script [ "before" ]
== sched error then ok
Go to Record/Request/Page [ Next ]
Set Variable [ $e ; Get ( LastError ) ]
== sched halt
Set Variable [ $a ; 1 ]
Halt Script
== sched no exit
Set Variable [ $a ; 1 ]
== sched exit empty
Exit Script [ "" ]
== sched exit date
Exit Script [ Date ( 1 ; 2 ; 2020 ) ]
== sched unknown step
Step 15
Exit Script [ "after unknown" ]
== sched sub
Perform Script [ "sched context" ; Parameter: "sub" ]
Exit Script [ "sub: " & Get ( ScriptResult ) ]
== sched dup
Exit Script [ "first" ]
== Sched Dup
Exit Script [ "second" ]
