# Validation of a repeating field (three repetitions), script-runtime.md
# 13.19. Title: not empty, strict, Always. Probe file contacts-notempty.fmp12: crates/om-server
# example validation_probe (rule notempty) over contacts-en; the @trigger line
# (never fired) makes runbat.sh run FMUpgradeTool's file generated from it.
# Each probe exits with Set Field's errors, then Commit Records' ("set/commit");
# a refused record is deleted (new) or reverted (Step 51), as a failed commit
# otherwise leaves the file unable to close (803 on the next run).
@trigger	Contact List	OnGestureTap	count
== ne none
Set Error Capture [ On ]
New Record/Request
Set Field [ Contacts::Company ; "x" ]
Set Variable [ $set ; $set & Get ( LastError ) ]
Commit Records/Requests [ With dialog: Off ]
Set Variable [ $e ; Get ( LastError ) ]
If [ $e ≠ 0 ]
Delete Record/Request [ With dialog: Off ]
End If
Exit Script [ $set & "/" & $e ]
== ne rep1 only
Set Error Capture [ On ]
New Record/Request
Set Field [ Contacts::Title[1] ; "a" ]
Set Variable [ $set ; $set & Get ( LastError ) ]
Commit Records/Requests [ With dialog: Off ]
Set Variable [ $e ; Get ( LastError ) ]
If [ $e ≠ 0 ]
Delete Record/Request [ With dialog: Off ]
End If
Exit Script [ $set & "/" & $e ]
== ne rep2 only
Set Error Capture [ On ]
New Record/Request
Set Field [ Contacts::Title[2] ; "b" ]
Set Variable [ $set ; $set & Get ( LastError ) ]
Commit Records/Requests [ With dialog: Off ]
Set Variable [ $e ; Get ( LastError ) ]
If [ $e ≠ 0 ]
Delete Record/Request [ With dialog: Off ]
End If
Exit Script [ $set & "/" & $e ]
== ne all three
Set Error Capture [ On ]
New Record/Request
Set Field [ Contacts::Title[1] ; "a" ]
Set Variable [ $set ; $set & Get ( LastError ) ]
Set Field [ Contacts::Title[2] ; "b" ]
Set Variable [ $set ; $set & Get ( LastError ) ]
Set Field [ Contacts::Title[3] ; "c" ]
Set Variable [ $set ; $set & Get ( LastError ) ]
Commit Records/Requests [ With dialog: Off ]
Set Variable [ $e ; Get ( LastError ) ]
If [ $e ≠ 0 ]
Delete Record/Request [ With dialog: Off ]
End If
Exit Script [ $set & "/" & $e ]
== ne clear rep2
Set Error Capture [ On ]
Go to Record/Request/Page [ Last ]
Set Field [ Contacts::Title[2] ; "" ]
Set Variable [ $set ; $set & Get ( LastError ) ]
Commit Records/Requests [ With dialog: Off ]
Set Variable [ $e ; Get ( LastError ) ]
If [ $e ≠ 0 ]
Step 51
End If
Exit Script [ $set & "/" & $e ]
== ne edit other
Set Error Capture [ On ]
Go to Record/Request/Page [ Last ]
Set Field [ Contacts::Company ; "y" ]
Set Variable [ $set ; $set & Get ( LastError ) ]
Commit Records/Requests [ With dialog: Off ]
Set Variable [ $e ; Get ( LastError ) ]
If [ $e ≠ 0 ]
Step 51
End If
Exit Script [ $set & "/" & $e ]
== ne clear rep1
Set Error Capture [ On ]
Go to Record/Request/Page [ Last ]
Set Field [ Contacts::Title[1] ; "" ]
Set Variable [ $set ; $set & Get ( LastError ) ]
Commit Records/Requests [ With dialog: Off ]
Set Variable [ $e ; Get ( LastError ) ]
If [ $e ≠ 0 ]
Step 51
End If
Exit Script [ $set & "/" & $e ]
== count
Exit Script [ ExecuteSQL ( "SELECT COUNT(*) FROM Contacts" ; "" ; "" ) ]
