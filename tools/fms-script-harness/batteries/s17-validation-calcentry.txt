# Validation of a repeating field (three repetitions), script-runtime.md
# 13.19. Website: by calculation Length ( Self ) <= 3, strict, only during data entry; seeded with an invalid repetition 1. Probe file contacts-calcentry.fmp12: crates/om-server
# example validation_probe (rule calcentry) over contacts-en; the @trigger line
# (never fired) makes runbat.sh run FMUpgradeTool's file generated from it.
# Each probe exits with Set Field's errors, then Commit Records' ("set/commit");
# a refused record is deleted (new) or reverted (Step 51), as a failed commit
# otherwise leaves the file unable to close (803 on the next run).
@trigger	Contact List	OnGestureTap	count
== seed
Set Error Capture [ On ]
Set Revert Transaction on Error [ Off ]
Open Transaction [ skip validation ]
New Record/Request
Set Field [ Contacts::Website[1] ; "toolong" ]
Commit Records/Requests [ With dialog: Off ]
Set Variable [ $c ; Get ( LastError ) ]
Commit Transaction
Exit Script [ $c & "/" & Get ( LastError ) & "/" & ExecuteSQL ( "SELECT Website FROM Contacts" ; "" ; "" ) ]
== edit rep2
Set Error Capture [ On ]
Go to Record/Request/Page [ Last ]
Set Field [ Contacts::Website[2] ; "ab" ]
Set Variable [ $set ; $set & Get ( LastError ) ]
Commit Records/Requests [ With dialog: Off ]
Set Variable [ $e ; Get ( LastError ) ]
If [ $e ≠ 0 ]
Step 51
End If
Exit Script [ $set & "/" & $e ]
== edit other
Set Error Capture [ On ]
Go to Record/Request/Page [ Last ]
Set Field [ Contacts::Company ; "x" ]
Set Variable [ $set ; $set & Get ( LastError ) ]
Commit Records/Requests [ With dialog: Off ]
Set Variable [ $e ; Get ( LastError ) ]
If [ $e ≠ 0 ]
Step 51
End If
Exit Script [ $set & "/" & $e ]
== count
Exit Script [ ExecuteSQL ( "SELECT COUNT(*) FROM Contacts" ; "" ; "" ) ]
