# Validation of a repeating field (three repetitions) reading a field that
# does not repeat, script-runtime.md 13.22 (battery s19). First Name: by
# calculation Self = Company[1] (Company has one repetition), strict, Always.
# Probe file contacts-extindex1.fmp12: crates/om-server example
# validation_probe (rule extindex1) over contacts-en; the @trigger line (never
# fired) makes runbat.sh run FMUpgradeTool's file generated from it. Each
# probe exits with Set Field's errors, then Commit Records' ("set/commit");
# a refused record is deleted.
@trigger	Contact List	OnGestureTap	count
== ext rep1
Set Error Capture [ On ]
New Record/Request
Set Field [ Contacts::Company ; "Acme" ]
Set Variable [ $set ; $set & Get ( LastError ) ]
Set Field [ Contacts::First Name[1] ; "Acme" ]
Set Variable [ $set ; $set & Get ( LastError ) ]
Commit Records/Requests [ With dialog: Off ]
Set Variable [ $e ; Get ( LastError ) ]
If [ $e ≠ 0 ]
Delete Record/Request [ With dialog: Off ]
End If
Exit Script [ $set & "/" & $e ]
== ext rep2
Set Error Capture [ On ]
New Record/Request
Set Field [ Contacts::Company ; "Acme" ]
Set Variable [ $set ; $set & Get ( LastError ) ]
Set Field [ Contacts::First Name[1] ; "Acme" ]
Set Variable [ $set ; $set & Get ( LastError ) ]
Set Field [ Contacts::First Name[2] ; "Acme" ]
Set Variable [ $set ; $set & Get ( LastError ) ]
Commit Records/Requests [ With dialog: Off ]
Set Variable [ $e ; Get ( LastError ) ]

Delete Record/Request [ With dialog: Off ]
End If

== ext rep2 only

End If
