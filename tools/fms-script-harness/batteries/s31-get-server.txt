# Every Get selector (catalogs/get-selectors.csv) in a server script
# session, after each step (@watch): a fresh session on the default layout,
# a new record, an edited field, the commit, another layout, a sort, Find
# mode with a request, Browse again, error capture, abort and a transaction.
# Base file: contacts-en.
== get probe
Set Variable [ $x ; 1 ]
New Record/Request
Set Field [ Contacts::First Name ; "Ann" ]
Commit Records/Requests [ With dialog: Off ]
New Record/Request
Set Field [ Contacts::First Name ; "Bob" ]
Commit Records/Requests [ With dialog: Off ]
Go to Layout [ "Contact List" ]
Sort Records [ Contacts::First Name ]
Go to Record/Request/Page [ First ]
Step 22
New Record/Request
Step 55
Set Error Capture [ On ]
Allow User Abort [ Off ]
Open Transaction
Commit Transaction
Exit Script [ "done" ]
